# digest-system

Master source-of-truth for Ross's personal knowledge & digest system (World Digest, Saturdays · Culture Digest, Sundays).

- `feeds/digest-feeds.opml` — the master feed list. Inoreader follows this file via OPML subscription; edit here, never in the app.
- `registry/source-registry.md` — human-readable map: sections, folders, access tiers, change log.
- `docs/setup-actions.md` — the manual Inoreader configuration (filters, thread monitors, output feeds).

Governed by the system constitution held in the Claude project. Source changes happen at the monthly review.
